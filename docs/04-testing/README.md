# Testing Documentation

Thư mục lưu trữ tài liệu kiểm thử cho dự án **Pixel Art AI Studio**.

---

## Danh mục tài liệu:
- **Test Plan:** Kế hoạch kiểm thử tính năng và chất lượng sinh ảnh AI.
- **Test Cases:** Các kịch bản kiểm thử cho Canvas Editor, luồng Export và độ chính xác của bảng màu.
- **Bug Reports:** Ghi nhận lỗi và kết quả kiểm thử định kỳ.
